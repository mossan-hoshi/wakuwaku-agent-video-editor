## 6. この回で分かったこと・注意

- **監視ループの生存判定**を bash の二重引用符内に PowerShell の `$_` で書くとエスケープが壊れ、**生きているのに「消えた」と誤報**する。判定は `.ps1` に書き出して `-File` で叩く（`scratchpad/alive_*.ps1`）。
- **600秒を超えた前景コマンドはハーネスが背景化し、メモリ不足で kill される**（NG モザイクの OCR で実害）。重い処理は最初から WMI 切り離し（`_scripts/*.cmd`＋`launch_*.ps1`）。OCR は1フレームごとにキャッシュするので再実行は続きから。
- 空きRAM は Chrome 等で 2〜6GB。WSL は起動していない（drop_caches は効かない）。
- `[IO.File]::ReadAllText` の相対パスは PowerShell の Location ではなくプロセスの cwd 基準 → **絶対パスで渡す**。
- bash の heredoc にシングルクォートを多用した Python を埋めると壊れた → **Write でスクリプトファイルを作ってから実行**。
- **G2 でユーザーは冒頭と後半を手で切る**。章の開始が kept 外に落ちる前提でコードを書く（§5.2）。
- イントロ構図: **体を背けて顔だけ振り返らせると首が折れる**（flare・2026-09-13）。体と顔の向きをそろえる。flare は `LIPSYNC_SAFETY` の「口を閉じる」を無視して口を開けた笑顔にしがち → situation 側にも closed-mouth を書く。
- flare の実寸: 16:9=1536x864、21:9=1792x768（`--image-size` は無視）。
- nano banana 2 の図解は日本語崩れ（「AIVIS ?命」「ススフドラマ風」）と枠の重複があった。flare 版は崩れなし。
