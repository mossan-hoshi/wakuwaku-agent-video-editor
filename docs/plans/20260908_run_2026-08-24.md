### 7.3 楕円モザイクの後処理（#107 専用・`data/2026-08-24/grow_mosaic.py`）

```bat
uv run python data\2026-08-24\grow_mosaic.py <入力mp4> <出力mp4> ^
  [--start 1.0] [--cx 0.50] [--cy 0.45] [--rx 0.40] [--ry 0.60] ^
```

  5秒でも2分を超えて終わらなかった。**PIL 版は全部で19秒**。縁の階調も PIL の方が作りやすい。

  ユーザーには動画で提示済み（未評価）。

- 🚨 **楕円は旧仕様**（`--shape ellipse` で残置）。2026-09-09 にユーザー指示で
  **`--shape full`＝画面全体**へ変更した。面積で強さを出せなくなるので、
  代わりに**ブロック辺長を 1px→`--block` へ伸ばす**。ffmpeg の `scale` は
  ブロック長を時間で動かせないため、フレームを PNG に開いて PIL で1枚ずつ潰している。
- 🚨 **赤フィルタはモザイクと同じ進み具合で強くする**（`--red`、既定 0.7）。
  **緑青を落とす掛け算**で作ること。赤を加算すると暗部まで発光して安っぽくなり、
  x264 で赤の輪郭が滲む。減算なら元の明暗がそのまま残る。
