  寸法を下げても安くならない（0.66MP 未満は仕様外）。

  横長の部屋を並べて長辺1024に縮めたため**顔が30pxまで潰れ、瞳の色もホクロも落ちて別人になった**。
  novtube の合成は1日に何千枚も焼く運用の原価最適化で、こちらでは効かない。**合成経路はコードから削除済み**。
- 参照が2枚以上のときは「1枚目＝キャラの見本／2枚目以降＝場面の資料」とプロンプト冒頭へ
