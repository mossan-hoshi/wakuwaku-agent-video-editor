# chibi-emotion-assigner — ちびキャラ感情割当

画面下に常時表示されるちびキャラ2体の**表情**を、会話の流れに合わせて切り替えるための感情割当。

**基調は normal で、はっきり感情が動いた瞬間だけ差す**。割当は「その発話の頭から数秒だけのリアクション」として再生され、すぐ normal に戻る（持続しない）。乱発するとメリハリが消えるので、迷ったら付けない。

## 入出力（ファイル経由・コンテキストに本文を載せない）

- **入力**: `data/<date>/chibi_emotion_input.tsv`。ヘッダ行あり、各行
  `key<TAB>time<TAB>speaker<TAB>audio<TAB>text`。
  - `key` = `<utterance添字>:<有声区間番号>`。**1行 = ひとつの有声区間**（発話まるごとではない）。
  - `audio` = **元の収録音声**を音声感情モデルに掛けた結果 `<ラベル>:<スコア>`。`-` は判定なし。
    ラベルは `angry/disgusted/fearful/happy/neutral/other/sad/surprised/unknown`。
  - `time` は出力タイムラインの mm:ss。
- **出力**: `data/<date>/chibi_emotion_decisions.json`。形式は厳密に
  `{"emotions": [{"key": "<key>", "emotion": "<感情>", "source": "audio|text|both"}, ...]}`。
  **normal は書かない**（差分方式・未割当=normal）。説明文・他のキーは書かない。

## 感情6種

`normal` / `smile`(笑顔・楽しい) / `surprised`(驚き) / `troubled`(困り・悲しみ) /
`angry`(怒り・ツッコミ) / `thinking`(考え中)

## 割当方針

**`audio` 列を最優先の根拠にする。** テキストだけでは「明らかに驚いている所」が拾えない
（声の高さ・強さ・立ち上がりは文字に出ない）。逆に `thinking` は音に対応物が無いので
テキストからしか拾えない。両方を使い分ける。

| audio 列 | どうする |
|---|---|
| `surprised` / `angry` / `happy` が **0.6以上** | 原則そのまま付ける（`source":"audio"`）。テキストが明らかに矛盾する時だけ落とす |
| 0.5〜0.6 | テキストが裏付けているときだけ付ける（`source":"both"`） |
| `neutral` / `-` / 0.5未満 | 基本は付けない。ただし `thinking`（「うーん」「どうだろう」と実際に考え込んでいる）はここから付けてよい（`source":"text"`） |
| `sad` / `fearful` / `disgusted` が 0.6以上 | `troubled` |

- **基調は normal**。付けるのは**全区間の1割まで**を目安にする。
  「なんとなくポジティブ/ネガティブ」では付けない。**表情がはっきり動いた瞬間だけ**。
- **間隔は区間数ではなく時刻で見る**。同じ話者に同じ感情を **10秒以内で続けない**。
  表情は数秒で normal に戻るので、20〜30秒空いていれば連続には見えない。
  「数区間空ける」で数えると、相槌が細かく割れている所で**必要な表情まで落ちる**
  （実走で288区間に対し20件まで減り、密度が足りなかった）。
- `surprised`: 「えっ」「マジですか」「そんなに!?」のような明確な驚きの発声があるとき
- `smile`: 声を出して笑った・うまくいった報告で明らかに嬉しそうなとき
- `troubled`: 失敗談・詰まった話を実際にしているとき（「うまくいかなくて」「ダメでした」）
- `thinking`: 「うーん」「どうだろう」と実際に考え込んでいるとき
- `angry`: ごく稀。強いツッコミ・理不尽への憤りのみ
- `normal` は書かない（未割当が normal）。感情はすぐ normal に戻るのでリセット指定は不要。

## キャラ個性の遵守（重要）

割当てた感情は**そのままキャラの表情になる**。話者に割当てられたキャラによっては表情の出方に制約がある（mascot.md 準拠・画像生成側で反映される）が、**感情割当の段階でも配慮する**:

- **yume はほぼ smile にしない**（ジト目・無表情が基本。よほどの盛り上がりでも thinking/normal 寄りに）。
- その他のキャラは通常の割当でよい。

## 例

```
key	time	speaker	audio	text
10:0	02:15	mossan-hoshi	neutral:0.71	でこれを実行するとですね、なんと3秒で終わるんですよ
11:0	02:22	Taniguchi	surprised:0.78	えっ、そんなに速いんですか
12:0	02:25	mossan-hoshi	sad:0.63	そうなんですよ、でも実はここでハマりまして
12:1	02:29	mossan-hoshi	neutral:0.55	どうだったかな、たしか設定が
```
→
```json
{"emotions": [
  {"key": "11:0", "emotion": "surprised", "source": "audio"},
  {"key": "12:0", "emotion": "troubled", "source": "both"},
  {"key": "12:1", "emotion": "thinking", "source": "text"}
]}
```

## 注意
- `key` は入力に存在するものだけ。創作しない。
- 出力はJSONのみ。所感や前置きをファイルに書かない。
