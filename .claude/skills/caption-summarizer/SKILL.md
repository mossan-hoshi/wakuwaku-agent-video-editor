# caption-summarizer — 要約字幕（要所・10〜15秒間隔）

勉強会録画の本編字幕を作る。**文字起こしそのままを全時間帯に出すのではなく**、会話の流れを読んで**要所だけ**を**短い要約**にし、おおよそ**10〜15秒間隔**で出す。視聴者が画面を見ながら要点を掴める“ダイジェスト字幕”。

## 入出力（ファイル経由・本文をコンテキストに残さない）

- **入力**: 窓TSV（引数のパス）。各行＝**カット後（無音/フィラー除去後）の約12秒の実発話窓**。`idx<TAB>out_time(mm:ss)<TAB>speaker<TAB>text`。out_time は最終動画上の時刻、text はその12秒で実際に喋った内容。
- **出力**: 決定JSON（指定パス）。形式は厳密に `{"captions":[{"utt":<窓idx>,"text":"<要約字幕>"}]}`。**それ以外のキー・説明文は書かない**。
- `utt` は字幕を出す**窓のidx**（コードが時刻へ変換）。時刻計算はしない。

## 手順

1. 入力TSVを読む（大きければ `wc -l` で行数確認後に分割して読む）。
2. 上から順に各窓を見る。窓は既に約12秒間隔なので、**原則1窓に1つの要約字幕**を作る（=10〜12秒間隔の密度が自然に出る）。
3. 各字幕の `text` にその窓の要点を短く要約して書き、`utt` にその窓idxを入れる。
4. **相槌・無言・挨拶だけの窓は飛ばす**（その窓は caption に入れない）。話が進んでいる窓は必ず字幕にする。
5. `{"captions":[...]}` を出力パスへ書く（`Write`）。

## 要約の方針

- **短く**: 1字幕は概ね全角28文字以内。長文は禁止（読めない）。
- **要約的に**: 逐語ではなく要点。「えーと、これはですね、FlashVSRっていう…」→「FlashVSRで動画を超解像」。
- **密度**: 原則1窓1字幕＝約12秒間隔。**疎にしすぎない**（実発話が続く窓は必ず字幕にする）。技術解説・具体例・数字・比較・手順は積極的に字幕化する。
- **飛ばすのは**: 純粋な相槌(「うんうん」)・無言・挨拶だけの窓。
- **固有名**: モデル名/論文名/ツール名（FlashVSR, SAM 3D, FastGS, YOLO-Master, MoE, 3D Gaussian Splatting 等）は正確に。STTが誤っている疑いがあれば、文脈や提供された画面OCRテキストで正す。
- **話者**: 基本は内容だけ。誰の発言かは原則書かない（必要時のみ）。
- **冒頭/締め**: 番組の決まり文句や挨拶だけの窓は字幕にしなくてよい。

## 例

入力（各行＝約12秒の窓・out_timeは最終動画上の時刻）:
```
idx  out_time  speaker       text
40   01:18     mossan-hoshi  えーと今日はCVPR2026の話で投稿が1万6千本くらい来てて
41   01:30     mossan-hoshi  その中でFlashVSRっていう動画の超解像のやつが面白くて
42   01:42     taniguchi     おお、なるほどはいはい
43   01:54     mossan-hoshi  DVD画質をフルHD超えまで上げられてしかもほぼリアルタイムで
```
出力(JSON):
```json
{"captions":[
  {"utt":40,"text":"CVPR2026、投稿は約1万6千本"},
  {"utt":41,"text":"注目：FlashVSRで動画を超解像"},
  {"utt":43,"text":"DVD画質→フルHD超にアップ"}
]}
```
（1窓1字幕＝約12秒間隔。idx42は相槌だけなので飛ばす）
